# Logging and Monitoring

## Log Sources
- Microsoft Entra ID Sign-in Logs
- Microsoft Entra ID Audit Logs
- Azure Activity Log
- PIM activation history

## What to Review
- Successful and failed sign-ins
- MFA prompts and outcomes
- Group membership changes
- Role assignments and removals
- PIM activation and expiration events

## Security Value
- Detect suspicious authentication attempts
- Confirm policy enforcement
- Track administrative changes
- Support incident response and audit readiness
