# Project Walkthrough

## Goal
Build a small Azure IAM security lab that demonstrates how Microsoft Entra ID identities are controlled and granted access to Azure resources using Zero Trust principles.

## Tasks Completed
1. Created test users in Microsoft Entra ID
2. Created security groups for access delegation
3. Assigned RBAC permissions to groups at the resource group scope
4. Planned Conditional Access policies to require MFA and block risky access
5. Defined PIM usage for privileged roles
6. Documented monitoring through sign-in logs and audit logs

## Outcome
This lab demonstrates practical Azure identity governance, least-privilege access, authentication hardening, and privileged access control aligned with cloud security and IAM engineering roles.
