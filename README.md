Azure Zero Trust IAM Lab

Overview

This project demonstrates how to implement Zero Trust security principles in Microsoft Azure using Microsoft Entra ID, Conditional Access, MFA, RBAC, and Privileged Identity Management (PIM).

Scenario

A company wants to secure its cloud environment by enforcing strong identity controls, least privilege access, and continuous monitoring.

Objectives
	•	Create users and groups in Microsoft Entra ID
	•	Enforce Multi-Factor Authentication (MFA)
	•	Configure Conditional Access policies
	•	Implement Role-Based Access Control (RBAC)
	•	Enable Privileged Identity Management (PIM)
	•	Monitor sign-in and audit logs

Technologies Used
	•	Microsoft Azure
	•	Microsoft Entra ID
	•	Azure RBAC
	•	Conditional Access
	•	MFA
	•	PIM
	•	PowerShell
	•	Microsoft Graph

Security Principles
	•	Zero Trust
	•	Least Privilege
	•	Just-In-Time Access
	•	Identity Governance
